# Submitted outputs and interpretation

The supplied project investigates:

1. Linearization, transfer functions, state-space poles, root locus and order reduction.
2. Open-loop step response, Bode/Nyquist plots and gain/phase margins.
3. PID controller examples (including saved step/impulse plots and Simulink models).
4. State-feedback pole placement and a separate nonlinear Simulink comparison.

**Scope warning:** The saved plots are original artifacts, not results newly reproduced in this packaging pass. Controller parameters vary between scripts and report sections. The nonlinear examples indicate that a controller intended for the linear model can perform poorly on the nonlinear model; inspect the saved figure and report rather than treating the controller as proven robust.

The detailed calculations, figures, and original discussion are in `reports/project_report.pdf` (Persian). The separate `references/assignment_brief.pdf` contains course requirements and is not the submitted result.
